# Briscola Creativa

Sitio web institucional desarrollado como proyecto final.

## Descripción

Briscola Creativa es una empresa ficticia dedicada al diseño de papelería personalizada para eventos familiares, especialmente comuniones, bautismos y cumpleaños.

El sitio presenta sus servicios principales, productos destacados, forma de trabajo y un formulario de contacto para solicitar presupuesto.

## Tecnologías utilizadas

- HTML5 semántico
- SASS
- CSS compilado
- Flexbox
- CSS Grid
- Responsive Design
- SEO básico

## Páginas del sitio

- Inicio
- Comuniones
- Bautismos
- Cumpleaños
- Contacto

## Estructura

El archivo `index.html` se encuentra en la raíz del proyecto.

Las páginas secundarias se encuentran dentro de la carpeta `pages`.

Los estilos SASS se organizan en partials dentro de la carpeta `scss`.

El CSS final se compila en:

assets/css/styles.css
